# 知识图谱与学习中心知识来源数据

本目录收录《知识来源书目.docx》中列出的公开知识来源，以及用户指定的《关圣帝君灵签》维基文库页面。主数据文件采用 **JSON 数组**，每个网页或公开文献入口对应一个对象。

## 文件说明

- `knowledge_sources_pages.json`：整理后的主数据，共 363 个对象。
- `validation.json`：字段、分类、正文、英文文本及重点页面的自动校验结果。
- `crawl_report.json`：网页抓取结果与无法访问的链接说明。
- `crawl_plan.json`：本次使用的网页及章节计划。
- `raw/`：已保存的原始 HTML 和 PDF，供复查解析结果。

## JSON 字段

每个对象包含以下英文字段：

- `url`：网页或文献入口地址。
- `title`：页面或章节标题。
- `source`：来源平台。
- `catalog`：该页面在书籍和知识体系中的层级位置。
- `category`：正文内容类型，可以同时包含多个值。
- `content`：中文正文，使用 Markdown 保留标题、正文、诗行和列表层级。
- `content_en`：网页本身提供的英文正文；没有时统一写为 `无`。

`category` 只使用以下四种值：

- `original`：经文、古籍正文或签诗原文。
- `commentary`：古代注释或传统签解，例如《彖传》《象传》及历代注释。
- `translation`：网页提供的现代白话译文，或 CText 页面本身提供的英文译文。
- `modern_commentary`：现代学者解释、现代研究或现代书目介绍。

由于同一网页可能同时包含经文、古代注释和译文，`category` 使用数组保存多个分类。英文内容只在来源网页确实提供时写入，不使用机器翻译补造。

## 数据范围

数据包括《周易》六十四卦与《易传》的 CText、维基文库页面及 CText 英文译文；《五行大义》《三命通会》《子平真诠》《滴天髓阐微》《穷通宝鉴》《渊海子平》《李虚中命书》《梅花易数》《增删卜易》《卜筮正宗》；《关圣帝君灵签》总目录与一百签页面；以及书目中列出的五种现代译注、校注或研究著作的公开书目页。

后续补充部分包括：已恢复访问的 CText《卜筮正宗》章节；用户提供的 362 页《穷通宝鉴》PDF全文；以及 luckclub 的《子平真诠评注》总目录与 52 个章节页面。luckclub 各正文页分别保留“原文”和“现代白话译文”，第 000 页为纯目录页。

《三命通会》的 CText 四库影印资源只保存十二卷目录及卷册链接。来源页面明确禁止自动批量下载，因此程序没有批量抓取影印图片。现代著作仅保存公开书目与简介，不复制受版权保护的完整书稿。

## 替代来源处理

- CText《卜筮正宗》章节重新访问后已成功获取完整正文。
- 普仁古籍《穷通宝鉴》页面由用户提供的 PDF 替代。
- 失效的《子平真诠评注》出版目录由用户指定的 luckclub 公开章节集合替代。

替换关系记录在 `crawl_report.json` 和 `validation.json` 中。目前没有未解决的失败链接。
