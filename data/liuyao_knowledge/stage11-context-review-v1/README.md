# 剩余疑似片段的上下文复核

本快照复制自 stage10，不覆盖原始资料。复核输入为 368 个疑似片段，合并为 87 个连续上下文组；来源、坐标、原文哈希均保留。决策由代理读取片段及其前后文后作出，不等于专家对古籍断法的审核。

## 核对结果

按原来的 368 个片段统计（不是独立案例数）：243 个理论、114 个占例组成片段、5 个作者评论、6 个混合片段。混合片段已按实际来源坐标拆分。

- 八宫全图、摇卦、纳甲、动变、飞伏等教学表格和假设示例归为理论，不能因含卦盘符号或“占得”就算历史占例。
- 作者的第一人称经验、方法批评和署名评语归为作者评论。理论与评论同段时按实际标记切开。
- 18 个完整历史事件恢复来源范围，其中 17 个此前未入 case 库；另 1 个对应现有“在任平安”case，原记录只保留问句和卦盘，此次补上同一来源的断语与结果，保留原 entity ID 并记录 previous_revision_id。旧修订不再占检索名额。
- 串联的复占保留为同一事件，不能拆成独立验证案例。同卦、同爻文或局部措辞相似不构成同一事件。
- 《卜筮正宗》中 6 段双列占例混排叙事确认为案例材料，仍保留原隔离状态，不能在未分清左右栏归属前当成独立案例召回。
- 当前分类表无 unresolved_case_fragment。原始 440 条隔离 passage 未解除隔离。

新增 18 个案例修订视图与 81 个理论／评论视图；移除 14 个包含新识别案例叙事的旧“理论”检索视图，并保留其非案例剩余内容。原向量复用，只为新增视图生成向量。

新增 99 个向量全部完成，活跃检索发布包含 224 个案例视图、264 个理论视图、135 个作者评论视图。全量来源及向量校验通过；健康、求职、婚恋、求财四类问事在关键词降级与真实语义检索下均可同时返回理论、评论和占例。

## 来源、关联和去重

每个新 case 保留完整原文、问句的原文位置、源区间与哈希。新修订同时关联其所属 passage 注释。跨源对照记录在 match_candidates 中；局部相似候选不会自动升级为同一事件关系。

原文只因文本完全相同或来源区间重叠才去重；相同的卦盘表格不用于判定两个事件相同。现有案例补全采用“同一来源、相同起点、已有原文是完整事件前缀”的身份条件，旧版与新版不会同时进入本发布。

`context_review_report.json` 包含逐项决策、完整事件边界、候选比较、移出旧视图及新增视图。`knowledge_passage_annotation` 存当前分类；stage10 存旧分类，可回溯修订。

## 运行和验收

在 fortune_module4 下：

```bash
.venv/bin/python -m scripts.review_liuyao_fragments --prepare-only
.venv/bin/python -m scripts.review_liuyao_fragments
.venv/bin/python -m scripts.validate_curated_passages --snapshot stage11-context-review-v1
.venv/bin/python -m scripts.validate_curated_passages --snapshot stage11-context-review-v1 --live
```

输入上下文文件有固定 SHA-256，资料改变后不能套用旧决策。全部向量完成及探针校验通过后才写 readiness 并切换 source_reading 发布。网页选择已就绪的 stage11，否则继续使用 stage10。

分类已完成，但原文中的 OCR、缺失爻行与古代论断不被自动修正；新案例明确保留这些限制，仍仅作类比材料，不启用确定性规则执行。
