# Data attribution

`cities.tsv` is derived from the GeoNames `cities15000` dump
(https://www.geonames.org/, https://download.geonames.org/export/dump/),
licensed under Creative Commons Attribution 4.0
(https://creativecommons.org/licenses/by/4.0/). Columns were reduced and rows
re-sorted by `build_cities.py`; coordinates and timezone ids are unchanged.
