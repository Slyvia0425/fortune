# 六爻确定性装盘 v1

2026-10-10。本次在既有三数字算法后增加装盘层，未修改上卦/下卦模八、第三数字模六的规则，未发布知识库或向量索引。

## 已实现与接入

`python_algorithm/liuyao_core.py` 计算八宫归属、世应、纳甲干支、六亲、六神、缺失六亲的本宫首卦伏神及飞伏关系。变卦六亲以本卦宫五行为参照，变卦本身不另外指定一组供本次取用的世应；静爻变卦位置仅供展示，只有本卦动爻带 transformation 关系。

每爻提供阴阳老少、动静、日月生克/冲合、月破、旬空、日月十二长生阶段（含墓绝）、月令旺相休囚死。返回动爻到其他本卦爻的关系，以及动爻变出爻的回头关系。

`hexagram_engine.py` 增加错卦、综卦，并修正互卦沿用本卦老阴/老阳数值的问题：互卦、错卦、综卦只保留结构阴阳，不继承动爻标记。

两个入口复用同一装盘模块：

- Python `/divination/cast`：返回 `core_facts`，使用服务器转交的冻结回执时间；无回执时取当前时间。拒绝无时区时间、非法时区和布尔数字。该底层算法接口不负责用户所有权，不能当作受信任盘面存储。
- 混合检索 `RuntimeStore.freeze`：生成真实完整 facts 并纳入 chart_hash，保留算法和装盘源码哈希。生产检索继续从用户所属的冻结记录读取，不接受客户端伪造 facts。

TypeScript结果契约已增加 `core_facts` 和错综卦字段，输入回执版本同步。页面未新增字段展示；已有解释模型仍需后续接新证据包。本次完成的是计算/数据接口，不声称已完成网页六爻解释。

## 固定计算口径

- core_version：`liuyao-decoration-v1`。
- calendar_policy：`shanghai-jie-midnight-water-earth-v1`。
- 依赖：固定 `lunar-python==1.4.8`；两个Python服务依赖文件均已声明。
- 时间：所有瞬间换算到 Asia/Shanghai 计算历法；用户IANA时区保留用于显示。境外用户不按当地午夜重新切换日辰。此为本版本明确的工程选择，不是唯一传统口径。
- 月建：按节的精确交接时刻换月；日辰：上海时间00:00换日，23:00仍算当天；不采用真太阳时。
- 范围：1901–2099年；超出拒绝。高分辨率时间保存在元信息，历法库以秒为单位计算。
- 六亲：以本卦所属宫五行为基准；伏神只列本卦缺失的六亲类别，取宫首卦对应爻位，保留可能的多个伏神。
- 旺衰：初版采用月支五行对应旺相休囚死，辰戌丑未按土月基线；不额外应用四季末若干日司令权重。十二长生采用水土同宫顺行表。

## 明确保留的判断边界

`overall_strength=null`、`overall_strength_status=requires_contextual_rule_evaluation`：已计算月令标签和日月/动变事实，没有虚构通用加权分数。用神综合旺衰的具体规则仍须可执行化；遇到这些字段的规则应返回unknown，不能让模型代算或把null当作弱。

`hidden.usable=null`：伏神位置和飞伏生克已计算，不等于一定可用。动爻与日冲等条件的最终作用，也不能只看单个标签推导。日冲不直接命名为暗动或日破；是否入墓、冲散、合化等语境判断交规则条件层。

`capability_gaps=[]`只表示本版声明的盘面事实字段已产出；不表示全部古籍断法已经编码。具体限制通过 `interpretation_limits` 与字段状态明确暴露。
