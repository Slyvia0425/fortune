# Module 3：知识图谱与学习中心

Module 3 是系统公共知识与证据的统一入口，不保存用户私人收藏或笔记。页面位于 `/knowledge`，包含四个相互连接的功能：典籍检索、概念图谱、术语解释和观点对比。

## 已实现功能

- **典籍检索**：对结构化资料的标题、目录和正文进行加权检索，可按内容层级及来源平台筛选。来源平台显示网站或资料库名称，不直接把网址当作名称。
- **原文阅读**：展示完整中文正文、来源本身提供的英文正文、目录路径、内容类型、来源编号和原网页链接。
- **概念图谱**：支持输入概念搜索，默认显示中心概念向外两层关系；单击任意节点会继续加载该节点周围的知识，悬停与选中均有视觉反馈。
- **术语解释**：按基础理论、八字命理、易学卦象和典籍阅读分类，用日常语言解释术语，并可跳转到对应图谱或典籍证据。
- **观点对比**：先给出术语在不同历史阶段的含义变化和主要差异，再按需展开原典、古代注释、现代译文与现代研究证据，不把不同作者观点强行合成同一结论。

## API

- `GET /api/knowledge/search?q=&category=&source=`：检索公共知识。`q` 可为空，用于浏览全部资料。
- `GET /api/knowledge/graph?concept=&depth=2`：返回指定概念及最多两层关系。
- `GET /api/knowledge/compare?q=`：返回总体结论、时期脉络、主要差异和来源证据。

所有接口沿用项目统一响应结构，并通过 `meta.sources` 返回可追溯的 `source_id`、标题和链接。Module 1 与 Module 2 可通过这些接口获取解释证据；Module 4 只保存 `source_id` 引用，不复制公共知识正文。

## 数据规则

`original`、`commentary`、`translation` 和 `modern_commentary` 四层在界面上分别展示。英文正文只在原网页确实提供时出现。现代版权资料仅展示公开书目信息或必要摘要，不把无来源生成内容标记为古籍原文。
